# サイト再構築プロンプト

このファイルは、このサイトを（ほぼ）一発で作り直させるための指示文です。
新しいセッションの最初の入力として、この内容をそのまま渡してください。

> **注意**
> 〈 〉で囲まれた箇所は、実際の値に置き換えてから渡してください。
> 架空の値を埋めたまま渡すと、そのまま架空の値でサイトが作られます。

---

## 1. 技術構成

- Next.js（App Router）/ TypeScript / Tailwind CSS
- デプロイ先は Vercel
- 画像・動画は `public/` 配下に置き、参照は `site-content.ts` 経由に統一する
- 追加ライブラリは最小限。アニメーションは CSS と `IntersectionObserver` で足りる範囲に留め、
  どうしても必要な場合だけ検討する

## 2. 最重要ルール

1. **文言・画像パス・数値などのコンテンツはすべて `src/lib/site-content.ts` に集約する。**
   コンポーネント側に文字列リテラルを直接書かない。あとから内容を差し替えるのは
   このファイル 1 枚を編集するだけで済む状態にすること。
2. **架空の値を入れない。**
   店名・住所・電話番号・営業時間・SNS の URL・料金・メニュー名などは、
   こちらが与えた値だけを使う。与えられていない項目は
   `TODO:` を値に入れて、どこが未入力かがひと目で分かる状態にする。
   もっともらしいダミーを作って埋めることは禁止。
3. 素材（写真・動画）が届いていない段階では、サイズだけ合わせたプレースホルダを置き、
   レイアウトを先に固める。

## 3. 雰囲気・配色

- 全体の印象: 〈例: 和モダン、余白が広く、静か〉
- ベース色: 〈例: 生成り #F5F1E8〉
- 文字色: 〈例: 墨 #1A1A1A〉
- アクセント色: 〈例: 朱 #B7412E〉
- 見出しフォント: 〈例: 明朝系〉/ 本文フォント: 〈例: ゴシック系〉
- 動きは「ゆっくり・少なく」。要素の出現はフェード＋わずかな上方向の移動まで。
  跳ねる・回る・派手にスライドするような動きは使わない。

## 4. セクション仕様

上から順に並べる。各セクションの具体値は〈 〉を埋めて渡すこと。

### ヘッダー
- 画面上部に固定（`position: sticky`）。スクロールで背景が不透明になる。
- 左にロゴ、右にナビゲーション（〈項目名を列挙〉）。
- スマホでは〈ハンバーガー / 下部固定〉に切り替える。

### ヒーロー
- 全画面（`100svh`）。〈静止画 / 動画〉を背景に敷く。
- 中央に筆文字ロゴ。下端にスクロール誘導のインジケータ。
- 見出し横の小さいキャプションは**置かない**。

### 〈セクション名〉
- 〈内容と枚数、並べ方、1 行あたりの列数（PC / スマホ）〉

### ギャラリー
- カードを 〈14〉 枚。PC 〈3〉 列 / タブレット 〈2〉 列 / スマホ 〈1〉 列。
- 動画がある項目はサムネイルを表示し、クリックで再生。
- 「VIEW MORE」のようなもっと見るボタンは**置かない**。全件を最初から並べる。

### マーキー（横流れ）
- 〈文言 / 画像〉を無限に横へ流す。速度は 〈約 40 秒で 1 周〉。
- 間隔は `gap` ではなく要素の `padding-right` で持たせる（理由は 6-3 を参照）。

### フッター
- 〈住所 / 営業時間 / SNS リンク / 地図〉

## 5. 特殊な機能

### 表裏モード
- 〈トグルの置き場所〉を押すと、サイト全体の配色と一部の文言が「表」「裏」で切り替わる。
- 切り替え状態は `localStorage` に保存し、次回訪問時も維持する。
- 状態の購読は `useSyncExternalStore` を使う（6-6 を参照）。

### 限定公開ゲート
- 〈対象のパス〉へのアクセス時に合言葉を要求する。
- 判定は Next.js の `proxy.ts`（旧 `middleware.ts`）で行い、通過したら Cookie を発行する。
- 合言葉は環境変数に置き、リポジトリに含めない。

### 素材取り込みスクリプト
- `scripts/` に、元画像を入れると配信用に変換して `public/` へ書き出すスクリプトを置く。
- 処理内容: EXIF の向きを画素に反映 → EXIF を削除 → リサイズ → WebP 出力。
- 動画はサムネイルを 1 枚書き出す。

## 6. 必ず守ること（実際に踏んだ落とし穴）

ここが一番重要です。以下は今回の制作で実際に時間を溶かしたもので、
知らないと同じところで必ず詰まります。

1. `html` / `body` に `overflow-x: hidden` を使うと、子孫の `position: sticky` が効かなくなる。
   横はみ出しを抑えたいときは `overflow-x: clip` を使う。
2. Tailwind v4 の `-translate-y-*` は `transform` プロパティではなく `translate` プロパティを動かす。
   `transform` を別途アニメーションさせていると噛み合わないので、どちらか一方に揃える。
3. マーキーの要素間隔を `gap` で取ると、1 周ごとに継ぎ目がずれる。
   間隔は各要素の `padding-right` として持たせる。
4. 画面外から流れてくるカード（マーキー内など）を遅延読み込みにすると、中身が空のまま出てくる。
   流れてくる要素は遅延読み込みの対象から外す。
5. Next.js 16 では `middleware.ts` は `proxy.ts` に改名されている。古い名前では動かない。
6. 効果（`useEffect`）の中で `setState` を呼んで外部状態に同期しない。
   `useSyncExternalStore` を使う。
7. 画像の EXIF は、向きを画素に反映してから削除する。順序を逆にすると横倒しになる。
8. ロゴの抜き文字は、白で塗りつぶすのではなく `fill-rule: evenodd` の穴として作る。
   背景色が変わっても破綻しなくなる。
9. 筆文字は画像として直接置かず、マスクとして敷いて `currentColor` で塗る。
   黒の素材のまま、配色の切り替えに追従する。
10. 写真の切り取り位置を数値計算だけで決めない。実物を並べて見比べて決める。
    （今回これで一度外し、並べ直した）
11. 確認は必ず実ブラウザで行う。dev サーバーを使い回すと古い chunk を配り続け、
    「CSS が当たっていない」ように見えることがある。疑わしいときはサーバーを立て直す。

## 7. 完成条件

以下がすべて通ったら完成とする。

- `npm run build` / `tsc --noEmit` / `npm run lint` がすべてエラーなし
- PC（〈1440〉px）とスマホ（〈390〉px）の実ブラウザで表示を確認
- 横スクロールが発生しない
- 画像・動画がすべて読み込まれる（コンソールに 404 なし）
- コンソールにエラー・警告なし
- `site-content.ts` に `TODO:` が残っていれば、その一覧を報告する
